# 🌟 موقع شخصي عربي عصري وأنيق (Arabic Personal Website)

موقع شخصي تم تصميمه وبرمجته بأحدث معايير الويب باستخدام **HTML5** و **CSS3** و **JavaScript**، مع دعم كامل وأصيل للغة العربية واتجاه الكتابة من اليمين إلى اليسار (**RTL**)، وبتنسيق لوني ملكي وجذاب باللونين **البنفسجي والأبيض**.

---

## 🎨 مميزات الموقع

1. **تصميم عربي أصيل (Native RTL):**
   - استخدام خط **Cairo** الأنيق من Google Fonts مع توافق مريح للأعين.
   - اتجاه من اليمين لليسار مع مراعاة الهوامش والخصائص المنطقية للغة العربية.

2. **باليتة ألوان عصرية (Purple & White):**
   - تناسق بين درجات البنفسجي الملكي والزاهي مع خلفيات بيضاء مريحة، وبطاقات ذات ظلال ناعمة وتدرجات ضوئية جميلة.

3. **الأقسام الأساسية المتكاملة:**
   - **قسم الترحيب (Welcome / Hero):** بطاقة شخصية عصرية، إحصائيات سريعة، شارة حالة تفاعلية، وأزرار دعوة لاتخاذ إجراء.
   - **قسم نبذة عني (About):** قصة وسرد تعريفي، ميزات رئيسية، وشبكة مهارات واهتمامات.
   - **قسم أهدافي (Goals):** بطاقات تفاعلية لتتبع الأهداف تشمل شريط تقدم، تصنيفات قابلة للفلترة، وإمكانية تمييز الهدف كمكتمل بنقرة زر مع تحديث فوري لنسبة الإنجاز.
   - **قسم التواصل (Contact & Footer):** بطاقات تواصل تشمل زر نسخ البريد الإلكتروني بنقرة واحدة مع تنبيه منبثق (Toast Notification)، وروابط شبكات التواصل الاجتماعي.

4. **تفاعل وحيوية (JavaScript):**
   - قائمة هاتف متجاوبة (Hamburger Menu) تفتح وتغلق بسلاسة.
   - تتبع التمرير النشط (Scroll Spy) وتحديد القسم الحالي في شريط التنقل تلقائياً.
   - فلترة وتصفية الأهداف حسب نوعها (تقنية، تعليمية، مهنية).
   - زر الرجوع إلى الأعلى (Scroll to Top) يظهر بسلاسة عند النزول لأسفل.
   - تنبيهات أنيقة (Toast Notification) عند نسخ البريد أو إكمال الأهداف.

5. **كود صديق للمبتدئين:**
   - هيكلة برمجية نظيفة مع تعليقات عربية مفصلة تشرح كل وسم وتنسيق ودالة.

---

## 📂 ملفات المشروع (File Structure)

| الملف | الوصف |
| :--- | :--- |
| **`index.html`** | الهيكل البنائي للموقع (HTML5 Semantic). يحتوي على عناصر شريط التنقل، قسم الترحيب، النبذة الشخصية، الأهداف، والتواصل. |
| **`style.css`** | ورقة الأنماط والتنسيقات. تعتمد على متغيرات CSS (`:root`) للتحكم في الألوان، وتدعم شاشات الحواسيب والهواتف بتصميم متجاوب كامل. |
| **`script.js`** | كود التفاعل والوظائف البرمجية الحية (القائمة المتجاوبة، فلترة الأهداف، تفاعل إكمال الهدف، نسخ البريد، زر الصعود). |
| **`README.md`** | دليل الاستخدام والتخصيص المفصل. |

## 🚀 طريقة تشغيل الموقع

الموقع مبني بملفات قياسية نقية، ولا يحتاج إلى أي تثبيت مسبق أو خوادم معقدة:
1. توجّه إلى مجلد المشروع.
2. انقر نقراً مزدوجاً على ملف **`index.html`** ليفتح في متصفحك المفضل (مثل Google Chrome أو Edge أو Firefox أو Safari).
3. سيعمل الموقع مباشرة بكل ميزاته وتأثيراته!

---

## ✏️ كيف تخصص الموقع لبياناتك الخاصة؟

### 1. تغيير الاسم والنبذة:
افتح ملف **`index.html`** في أي محرر نصوص (مثل VS Code أو Notepad):
- ابحث عن اسم `مُهند أحمد` واستبدله باسمك الكامل.
- ابحث عن وسم الفقرة `<p class="hero-description">` لتكتب مقدمتك الخاصة.
- في قسم `about-section`، عدّل فقرات نبذة عني لتطابق مسيرتك واهتماماتك.

### 2. إضافة صورتك الشخصية:
داخل قسم الترحيب في `index.html`، ستجد الحاوية:
```html
<div class="avatar-circle">
    <!-- يمكنك استبدال أيقونة الـ SVG بصورة حقيقية لك كالتالي: -->
    <!-- <img src="my-photo.jpg" alt="صورتي الشخصية" style="width:100%; height:100%; border-radius:50%; object-fit:cover;"> -->
</div>
```

### 3. تعديل الأهداف:
في قسم `goals-section`:
- يمكنك تغيير نصوص الأهداف، نسب الإنجاز (`style="width: 70%;"` ومطابقتها في نص النسبة `70%`).
- لإضافة هدف جديد، انسخ قالب أي `<article class="goal-card">` وعدّل التصنيف في خاصية `data-category="tech"` (أو `learning` أو `career`).

### 4. تحديث روابط التواصل والبريد:
- استبدل `your-email@example.com` ببريدك الإلكتروني في زري النسخ وبطاقة الاتصال.
- ضع روابط حساباتك الحقيقية على `GitHub` و `LinkedIn` و `X (Twitter)` في الروابط المخصصة لها داخل قسم `contact-section`.

### 5. تخصيص الألوان (اختياري):
إذا أردت تغيير درجات الألوان، افتح ملف **`style.css`** وعدّل المتغيرات في البداية:
```css
:root {
    --primary: #7c3aed;       /* اللون البنفسجي الملكي الأساسي */
    --primary-hover: #6d28d9; /* اللون عند تمرير الفأرة */
    --primary-light: #f5f0ff; /* خلفيات بنفسجية فاتحة وناعمة */
}
```
